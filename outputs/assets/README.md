# graph tool application icon

Generated with the built-in imagegen tool. The PNG is the master artwork; ICO and ICNS are deterministic format/size conversions for Windows and macOS. The application uses the same artwork for its window icon and header. Preview: [graph-tool-icon.png](graph-tool-icon.png).

Final generation prompt:

> Use case: logo-brand. Asset type: a single production desktop application icon for a TEM scientific image scale-bar editor named graph tool. Create one square 1024x1024 icon, front-facing orthographic composition. Deep navy rounded-square tile occupying 88% of the canvas; actual transparent alpha outside the tile. Within the tile, a restrained cyan circular microscope-field rim behind three large, softly beveled nanocrystal hexagons in white and icy cyan, arranged as a readable compact cluster. A bold white horizontal scientific scale bar with two short vertical endcaps sits below the particles, separated clearly from them. Style: polished macOS scientific utility icon, minimal geometric dimensional illustration, subtle depth, clean edges, high contrast and strong silhouette readable at 16px. Palette follows an existing blue scientific desktop UI: navy, cyan, ice blue, white. Leave generous internal padding. No text, letters, digits, watermarks, collage, multiple variants, device mockup, extra frame, or scene. One isolated icon only. Preserve transparent corners.

The generated master is 1254×1254 RGBA. ICO contains 16/24/32/48/64/128/256 px entries; ICNS contains the macOS resolution set generated by Pillow.
